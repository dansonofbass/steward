# Bundled reference data

Every file here is a published table copied verbatim or derived by the stated rule.
Fetched 2026-10-13 unless a line says otherwise. Units are as published (dollars);
the engine converts at its boundary.

Tax and benefit rules live in `rules/<topic>_<year>.json`, one table per topic and year; each carries its own `source`, `year` (or `effective_from` / `effective_to`) and `checked` date, and `tests/engine/test_rules.py` fails on any table without them. The checklist's 401(k), IRA and HSA limits come from `rules/retirement_2026.json`.
