# Thoughtfulness review of Steward 0.1.0

Before the 0.1.0 release, Steward went through a release gate: separate reviews for security, privacy and thoughtfulness, a fourth review of the web platform, and an install from the docs on a clean machine. This page sums up what touches how Steward treats the people using it. The [security](0.1.0-security.md) and [privacy](0.1.0-privacy.md) summaries cover the rest.

## What was checked

A fresh reviewer read the code of the 0.1.0 tree and looked at every screen:

- all 72 screens, on a phone and a laptop, in dark and light, and 6 moments on a phone (an Undo toast, a delete confirm, a red month, a failed bank sync, Ask's preview of what Claude will see, and a celebration with reduced motion);
- the copy: plain words, no internal terms, nothing said that the screen doesn't know;
- Undo and confirm: every removal, and whether anything leaves without a word;
- money worries: no cheer beside bad news;
- accessibility: what a screen reader hears, the keyboard path, focus after a sheet closes, and reduced motion;
- the first run: setup, the welcome and Get Steward ready.

A fourth reviewer looked at the web platform: sheets and dialogs, forms and their errors, live regions, page changes, colour schemes and forced colours, touch targets, layout shift, fonts, the first download, time zones and typing in other scripts.

## How

- The reviewer read the code and walked every screen on a phone in dark mode first, as pixels and as accessibility snapshots, then compared light and the laptop. [T5](../CLAIMS.md#t5) It also read the keyboard trace and the automated accessibility results (axe, 144 passes and no exceptions). [T7](../CLAIMS.md#t7)
- The web reviewer read the browser code against current platform guidance.
- Each reviewer was an AI model working alone, on its own copy of the code, with no view of the other reviews.
- Every fix was checked again by a fresh reviewer. The web fixes took three rounds: the re-checks found, for example, that a second Escape in Chrome could still throw away typed text. All of it was fixed before merge.

Before release, an AI agent that had never seen the code installed Steward on a clean Ubuntu 26.04 virtual machine by following only the docs ([install](../quickstart/install.md), [LAN only](../guides/access.md#lan-only) and [importing a file](../guides/bank-data.md)), with the release images already loaded: 1 min 21 s from `git clone` to a signed-in Steward with a bank file imported. That is an agent's time, not a person's: it reads and types far faster, and the time leaves out the image download. Its own estimate for a person is 10 to 15 minutes plus the download. The first run took 2 min 52 s and found two Important gaps in the docs, both fixed before the second. The demo took 27 s from start to signed in, also with the images loaded.

## What was found

Critical means a claim is false in a way that loses data or exposes it; Important means a pillar promise is broken on a real flow, or an install step needs knowledge the docs don't give; Minor is polish or unclear wording.

| Severity | Count |
|---|---|
| Critical | 0 |
| Important | 8 |
| Minor | 50 |

The thoughtfulness review found 2 Important and 14 Minor, the web review 4 Important and 14 Minor, and the install 2 Important and 22 Minor.

## What was fixed

- After a confirmed removal, nothing said what went, and focus fell to the top of the page. Each removal now says what was removed, and focus lands on something still there.
- Settings › Chat drew a cross beside words that said a check passed, and a screen reader heard only the words. A failed check now says so in words.
- On Android, the back gesture with a sheet open left the page and lost what was typed. Sheets are now native dialogs: back closes the sheet, and leaving with typed text asks first.
- A new page opened at the old page's scroll position. It now opens at the top, and Back returns to where you were.
- Every page was titled "Steward", and a screen reader heard nothing on a page change. Each page has its own title, and a page change moves focus to its heading.
- A failed save was silent to a screen reader. Focus now moves to the first field with an error.
- The LAN only guide didn't say how to give the machine a name, and a plain IP address failed without a word. It now gives three ways, with a check, and the proxy says why it refuses an address.
- LAN only had no way to trust the certificate on a Linux computer. It now does, for the system and for each browser.
- Review's sort cheer played in a red month and on a fee. A sort now draws no cheer in either case. [T6](../CLAIMS.md#t6)

Most Minors were fixed in the same work: the Undo toast and copy buttons are heard, forced colours keep selections visible, custom radio groups take the arrow keys, typing in another script no longer saves early, and the install and demo pages match what the screens show. With these fixes, nothing vanishes unseen: a removal says what went, a change that can be undone offers Undo, and typed text isn't dropped without asking. [T1](../CLAIMS.md#t1)

## What's left

These Minor findings become public issues after the release. The last three were noticed in passing during the install's re-check, and "Pages for one item" came from the re-check of the web fixes.

- Home's stale-account line states a count and an age it doesn't know.
- The Fix link for a SimpleFIN sign-in opens a page with no fix.
- Home and Plan show different retirement ages.
- "Up 5 years" under a retirement age that went down.
- The reset page with no link, or an old one, shows the full form.
- The setup link's expired message gives the command in a form the install doesn't use.
- Some screens skip a heading level or have none.
- Phone layout: a word break on Business rules, the toast's dot when Undo wraps, a tab row that wraps one tab.
- Info notices and Review's caught-up line arrive with their text already in their live region.
- Home shifts down when the month strip and "Since you last looked" arrive.
- Fonts aren't preloaded, and their fallbacks aren't matched in size.
- "Today" follows the device's time zone, not the household's.
- Desktop menus are placed and dismissed in script.
- Type is sized in pixels, so the phone's text size setting doesn't reach it.
- Pages for one item, such as an account, share a title.
- In the demo, Home goes to Profile until a card there is dismissed.
- One demo account's owner matches no one in the demo household.
- After a first import, "1 waits in Review" isn't explained.
- Home says the first month is fully sorted while a row still waits in Review.
- Home's chart names December in November.
- `steward setup` prints UTC as the time zone, while the welcome shows the browser's.
